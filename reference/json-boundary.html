JSON 경계 치트시트

C# ↔ JSON ↔ TS. 타입을 만들 때마다 묻기: "이 값은 경계 반대편에서 어떻게 보이지?"

타입 대응 (System.Text.Json, 웹 기본값)

C#JSONTS
ChildId (속성 이름)"childId"childId
Guid문자열string
DateTimeOffset"2026-11-04T21:30:00+09:00"string
enum (기본)숫자 1⚠️ 숫자
enum + JsonStringEnumConverter"Poo""Pee" | "Poo" | "Both"
string? = null (기본)"memo": nullmemo: string | null
string? = null + WhenWritingNull키 없음memo?: string

들어오는 JSON에서 조심할 것

입력결과
required 키 없음❌ JsonException
enum 이름이 틀림 ("Rainbow")❌ JsonException
enum 소문자 ("poo")✅ 통과
enum 범위 밖 숫자 (99)⚠️ 통과 → 서비스에서 Enum.IsDefined로 검증
숫자 자리에 문자열 ("120")✅ 통과 (웹 기본값 AllowReadingFromString)
의미상 잘못된 값 (-50 ml)⚠️ 통과 → 서비스에서 검증
오프셋 없는 시각⚠️ 실행 환경의 시간대로 해석 → 항상 오프셋 붙여 보내기

직렬화기는 형식만 지킨다. 의미는 서비스가 검증한다.

설정은 앱 전체에 한 번만

var options = new JsonSerializerOptions(JsonSerializerDefaults.Web);
options.Converters.Add(new JsonStringEnumConverter());
